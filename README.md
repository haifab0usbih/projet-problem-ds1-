# projet-problem-ds1-

A clean, modern static website built with HTML, CSS, and JavaScript.

## Getting Started

This is a static site. To view it, you can simply open the `index.html` file in any modern web browser or run a simple local web server from the project directory.

## Project Structure

*   `index.html`: The main entry point for the website.
*   `styles.css`: Contains the CSS styling for the site.
*   `script.js`: Contains the JavaScript logic for interactions.

## Features

*   Responsive navigation menu
*   About section
*   Services overview
*   Contact information
